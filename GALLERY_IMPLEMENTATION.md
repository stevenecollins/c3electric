## Feature Overview

An interactive horizontal-scrolling masonry gallery with carousel navigation and lightbox functionality for the project portfolio section.

## Key Features

### 1. Masonry Grid Layout
- **Style:** Pinterest/masonry-style grid with mixed image orientations
- **Image Types:**
  - Landscape images: ~600x400px (half-height in grid)
  - Portrait images: ~400x600px (full-height in grid)
- **Layout:** Horizontal scrolling container showing ~5 images at a time
- **Scroll Distance:** 50% of container width per navigation click (partial overlap)

### 2. Navigation Controls

#### Desktop & Tablet
- **Left Chevron:** Appears after first navigation, scrolls gallery right (back)
- **Right Chevron:** Always visible initially, scrolls gallery left (forward)
- **Behavior:** Chevrons disable when reaching start/end of gallery
- **Position:** Overlaid on left/right edges of gallery container

#### Mobile
- **Touch Swipe:** Swipe left/right to navigate gallery
- **Chevrons:** Small chevron indicators still visible for discoverability
- **Snap Points:** Gallery snaps to prevent awkward image cutoffs

### 3. Image Interactions

#### Hover Effect (Desktop/Tablet)
- Image scales up by 10% on hover
- Smooth transition animation
- Maintains aspect ratio

#### Click to Open Lightbox
- Click any image to open in full-screen lightbox modal
- Lightbox displays image at larger size, centered on dark overlay

### 4. Lightbox/Modal Features

#### Controls
- **Close Button (X):** Top-right corner, closes lightbox
- **Previous Arrow:** Left side, cycles to previous image
- **Next Arrow:** Right side, cycles to next image
- **Click Outside:** Clicking dark background closes lightbox (except on arrows)

#### Navigation
- Arrow keys (left/right) also navigate between images
- Cycles through all gallery images in order
- Maintains image index position

### CSS Architecture

#### Gallery Container
- `display: flex` with horizontal scroll
- `overflow-x: auto` with hidden scrollbar
- `scroll-behavior: smooth` for animated scrolling
- `scroll-snap-type: x proximity` for snap points

#### Masonry Grid
- JavaScript calculates column layout based on image orientations
- CSS handles sizing and spacing
- Responsive breakpoints:
  - Desktop (1024px+): ~5 images visible
  - Tablet (768-1023px): ~3 images visible
  - Mobile (320-767px): ~2 images visible or single column

#### Chevron Buttons
- Position: `absolute`, overlaid on gallery edges
- Style: Circular buttons with semi-transparent background
- Disabled state: Reduced opacity, no pointer events
- Mobile: Smaller size, better touch target

#### Image Hover Effect
```css
.gallery__image {
    transition: transform 0.3s ease;
}

.gallery__image:hover {
    transform: scale(1.1);
    z-index: 10;
}
```

#### Lightbox Modal
- Fixed position overlay covering viewport
- Dark background: `rgba(0, 0, 0, 0.9)`
- Image centered with max-width/max-height
- Controls positioned absolutely
- Hidden by default: `display: none`
- Active state: `display: flex`

### JavaScript Implementation

#### Image Data Array
```javascript
const galleryImages = [
    {
        src: 'https://placehold.co/600x400/2d2462/ffffff?text=Project+1',
        alt: 'Electrical panel installation',
        orientation: 'landscape'
    },
    {
        src: 'https://placehold.co/400x600/2d2462/ffffff?text=Project+2',
        alt: 'Generator setup',
        orientation: 'portrait'
    },
    // ... 12-15 total images
];
```

#### Core Functions

1. **`generateGallery()`**
   - Loops through `galleryImages` array
   - Creates DOM elements for each image
   - Applies appropriate classes based on orientation
   - Attaches click event listeners for lightbox

2. **`updateChevronStates()`**
   - Checks scroll position of gallery container
   - Enables/disables left chevron (disabled at start)
   - Enables/disables right chevron (disabled at end)
   - Called on scroll and resize events

3. **`scrollGallery(direction)`**
   - Calculates 50% of container width
   - Scrolls left or right by that amount
   - Uses `scrollBy()` with smooth behavior

4. **`handleTouchSwipe()`**
   - Listens for `touchstart`, `touchmove`, `touchend`
   - Calculates swipe direction and distance
   - Triggers scroll if swipe threshold met
   - Prevents default scrolling behavior

5. **`openLightbox(imageIndex)`**
   - Shows lightbox modal
   - Loads selected image
   - Stores current image index
   - Adds keyboard event listeners (arrow keys, escape)

6. **`closeLightbox()`**
   - Hides lightbox modal
   - Removes keyboard event listeners
   - Resets image source

7. **`navigateLightbox(direction)`**
   - Changes to next/previous image in array
   - Handles wraparound (cycles to start/end)
   - Updates lightbox image source and alt text

#### Event Listeners
```javascript
// Chevron navigation
leftChevron.addEventListener('click', () => scrollGallery('left'));
rightChevron.addEventListener('click', () => scrollGallery('right'));

// Scroll tracking
galleryContainer.addEventListener('scroll', updateChevronStates);

// Touch swipe (mobile)
galleryContainer.addEventListener('touchstart', handleTouchStart);
galleryContainer.addEventListener('touchmove', handleTouchMove);
galleryContainer.addEventListener('touchend', handleTouchEnd);

// Lightbox controls
lightboxClose.addEventListener('click', closeLightbox);
lightboxPrev.addEventListener('click', () => navigateLightbox('prev'));
lightboxNext.addEventListener('click', () => navigateLightbox('next'));
lightboxOverlay.addEventListener('click', (e) => {
    if (e.target === lightboxOverlay) closeLightbox();
});

// Keyboard navigation in lightbox
document.addEventListener('keydown', (e) => {
    if (lightbox is open) {
        if (e.key === 'ArrowLeft') navigateLightbox('prev');
        if (e.key === 'ArrowRight') navigateLightbox('next');
        if (e.key === 'Escape') closeLightbox();
    }
});
```

## Managing Images

### Adding/Removing Images (Current Standalone Version)

1. Open `script.js`
2. Find the `galleryImages` array (near top of gallery section)
3. Add or remove image objects following this format:

```javascript
{
    src: 'path/to/image.jpg',           // Image URL or path
    alt: 'Description of the image',     // Alt text for accessibility
    orientation: 'landscape' // or 'portrait'
}
```

4. Save the file - gallery will automatically regenerate

### Tips for Image Selection
- Use a mix of landscape and portrait orientations (roughly 60% landscape, 40% portrait)
- Keep image sizes consistent (landscape: 600x400, portrait: 400x600)
- Optimize images for web (compressed JPGs, 80-90% quality)
- Use descriptive alt text for accessibility

## Troubleshooting

### Common Issues

**Chevrons not disabling:**
- Check scroll position calculation in `updateChevronStates()`
- Verify container scrollWidth vs clientWidth

**Images not scaling on hover:**
- Check z-index and overflow settings
- Ensure transform-origin is set correctly

**Swipe not working on mobile:**
- Verify touch event listeners are attached
- Check for conflicting scroll behavior
- Test preventDefault() calls

**Lightbox not closing:**
- Check event propagation (e.stopPropagation on arrows)
- Verify event listener on overlay background
- Test ESC key listener

**Gallery not scrolling smoothly:**
- Verify `scroll-behavior: smooth` in CSS
- Check for JavaScript scroll conflicts
- Test scrollBy() vs scrollTo()
